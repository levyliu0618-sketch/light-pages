Arduino setup

Screen only. No physical lights are connected.

Use Chrome and the local launcher. Upload the included V2 two-light sketch; close Arduino Serial Monitor before connecting.

Disconnect the servo’s power and signal; disengage its drive before opening the book by hand. Keep each LED’s series resistor. Only D6 and D11 are used.

V2 firmware required. Revisit → left / A / D6. Another view → right / B / D11. Compare → both on. Board acknowledgement confirms a command, not measured light output.

The on-screen glow is an illustrative memory cue, not a recorded light trace. These photos illustrate the concept, not one synchronised journey. No recording runs on this page.
